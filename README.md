# ENDLESS PUZZLE

スリザーリンクとマインスイーパーを、問題を自動で作り続けて終わりなく遊べるアプリ。

- スリザーリンク：答えが1つだけの問題を、かんたん／ふつう／むずかしい × 6×6・8×8・10×10 で作る
- マインスイーパー：当てずっぽうなしで最後まで解ける盤面だけを出す（初級・中級・上級）
- ヒント・一手戻す・セーブポイント・途中保存・記録（端末の中だけ）
- 一度開けばネット無しでも遊べる（ホーム画面に追加できる）

ファイル：`index.html`（画面）／`gen.js`（問題づくり）／`sw.js`（ネット無し）／`manifest.webmanifest`・アイコン
